# Neon Drift

A fast, dependency-free arcade survival game built in a single HTML file (canvas + vanilla JS).

## How to play
Open `index.html` in any browser.

- **Move**: mouse, arrow keys, or WASD
- **Space**: slow/boost-brake for precision dodging
- Dodge red shards flying in from the edges
- Grab cyan orbs for score + combo multiplier
- Grab magenta bolts for a temporary shield (absorbs one hit)
- Survives longer = faster & harder

Best score is saved locally in your browser.
